# 1 文件结构说明

目前经过完善后，我已经写完了分配、r相关的部分，累计4个文件夹。

**DAC_without_insurence**：没有引入保险时单个节点的响应概率r随着贿赂金额的变化情况。

**DAC_with_insurence**：有保险机制时单个节点的响应概率r随着贿赂金额的变化情况。

**DAC_allocator**：比较原始，但是时间复杂度很高的贿赂金额分配对系统响应情况的影响。(可以不用看)

**Fast_DAC_allocator**：在**DAC_allocator**的基础上大幅提速了，剩下没区别。

# 2 参数调整

## 2.1 DAC_without_insurence

调节parameter.m中的对应参数即可。如果想要看单一贿赂金下的对应解，运行demo.m即可，想看解随着贿赂金变化的情况，运行main.m。

## 2.2 DAC_with_insurence

同2.1。

## 2.3 Fast_DAC_allocator

运行main.m查看系统的未响应概率随着贿赂金为5元的比例变化的图像。

修改参数方法：

1. 在Node.m中，我定义了一个节点类，其中properties的部分，使用等于号直接赋值的参数可以在这里修改。其他参数需要后续手动从外部传入。

2. 在main.m中，是我对节点类的实例化，语句格式为：

   ```matlab
   xxx=Node(a,b,c,d);
   ```

   其中，a为系统中节点数量，变量名为num_nodes，b为节点接到的贿赂金额，c为是否引入保险机制（true为引入，false为不引入），d为文件价值。

修改上面的几个位置即可修改所需要的全部参数。

注意：分配策略为5的节点数为偶数，2.5和7.5的节点在剩下节点中各占一半。
